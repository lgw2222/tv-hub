TV Remote Hub

One phone remote for every Roku, Google TV and Fire Stick in the house.

This site holds the app's files. The remote itself runs on your PC inside Server Hub, because controlling TVs on your Wi-Fi can't be done from a web page. Install it by pasting the address below into Server Hub.

Paste this into Server Hub's Add an app

Steps

  1. Have Server Hub running on the PC.
  2. Open Server Hub on your phone and paste the address above into Add an app.
  3. Tap Install app. It downloads, gets a port and starts.
  4. Open the app's link from its card and add that to your home screen.
  5. Add your TVs, or tap scan to find Rokus automatically.

Rokus need only their IP. Google TVs and Fire Sticks need ADB on the PC plus a one-time Allow on the TV.
